# Contributing

Source code for [Arnaud Jalbert](README.md)'s personal website.

## Stack

Built with [Astro](https://astro.build). English lives at `/en/`, French at `/fr/`. `/` redirects to `/en/`.

## Commands

```sh
npm install
npm run dev      # local server
npm run build    # static site in dist/
```

## Deployment

Deployed on Cloudflare Pages: build command `npm run build`, output directory `dist`. Every pull request gets a preview build.

## Pull requests

Pull requests merge with squash and merge only, and the branch is deleted after the merge.
